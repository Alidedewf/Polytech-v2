# PolyTechPark — Frontend

Это клиентская часть (Frontend) корпоративного веб-сайта **АО «PolyTechPark»** (технопарка в строительной отрасли при Satbayev University). Проект реализован с акцентом на современный дизайн (Glassmorphism), высокую производительность и SEO.

## Технологический стек

* **Фреймворк:** [Next.js 15](https://nextjs.org/) (App Router)
* **Библиотека:** React 19
* **Стилизация:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Мультиязычность (i18n):** `next-intl` (Поддержка RU, KK, EN)
* **Шрифты:** Montserrat (через `next/font/google`)

## Быстрый старт

### 1. Установка зависимостей
Убедитесь, что у вас установлен Node.js (рекомендуется v20+). Перейдите в папку `frontend` и выполните команду:
```bash
npm install
```

### 2. Запуск сервера для разработки
Запустите локальный сервер:
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере. Вы увидите главную страницу сайта.

## Структура проекта

* `src/app/` — основные страницы проекта (Next.js App Router).
  * `[locale]/` — динамический роутинг для мультиязычности (например, `/ru/about`, `/kk/about`).
* `src/components/` — переиспользуемые UI компоненты (например, `Header.tsx`, `Footer.tsx`, карточки, баннеры).
* `src/i18n/` — настройки мультиязычности.
* `messages/` — JSON-файлы с переводами (`ru.json`, `kk.json`, `en.json`).
* `public/` — статические файлы (логотипы, изображения, иконки).

## Мультиязычность
Сайт поддерживает 3 языка. Язык по умолчанию — русский (`ru`).
Тексты хранятся в папке `messages/`. Для добавления новых текстов необходимо обновить все три файла (`ru.json`, `kk.json`, `en.json`), а затем использовать хук `useTranslations` в нужных компонентах.

## Сборка для продакшена
Для создания оптимизированной production-сборки:
```bash
npm run build
npm run start
```
